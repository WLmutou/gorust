gorust is an experimental library that brings Go-like concurrency patterns to Rust: goroutines, channels, lightweight scheduling, and a familiar API for developers moving between Go and Rust or wanting Go-style concurrency in Rust projects.

View on GitHub See Usage

About

The primary goal of gorust is to provide Rust developers with familiar concurrency primitives similar to those found in Go, especially Goroutines and channels, enabling lightweight concurrent programming experiences and reducing the learning curve when transitioning between the two languages.

Installation

Add gorust as a dependency via git (or from crates.io once published).

Cargo.toml
[dependencies]
gorust = { git = "https://github.com/WLmutou/gorust.git" }

Quick Start

Use #[runtime], go, channel, WaitGroup and more.

main.rs
use gorust::{runtime, go, channel, sleep};

#[runtime]
fn main() {
  let (tx, rx) = channel::new();

  go(move || {
    sleep(std::time::Duration::from_millis(100));
    tx.send("Hello from goroutine!".to_string()).unwrap();
  });

  let message = rx.recv().unwrap();
  println!("{}", message);
}

Features

Planned and in-progress capabilities to make Go-style concurrency feel natural in Rust.

Goroutines

Go-style goroutines implementation in Rust with lightweight scheduling.

Channels

Channel communication between concurrent tasks, similar to Go’s chan.

Select-like

Provide select-like functionality similar to Go (on the roadmap).

WaitGroup

Synchronization helper so one task can wait for multiple goroutines.

Familiar API

API designed to feel intuitive for developers experienced with Go concurrency.

Examples & Tests

Comprehensive examples, docs, tests and benchmarks planned in the roadmap.
